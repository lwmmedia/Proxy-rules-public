Qu'est-ce qu'un proxy transparent et filtrant ?

Un proxy transparent et filtrant pour iOS permet de router intelligemment votre trafic Internet en fonction de règles prédéfinies. Il agit comme un intermédiaire entre votre appareil et Internet, vous permettant de :

  • Accéder aux services géo-restreints (Netflix, YouTube, etc.)
  • Améliorer la sécurité et la confidentialité de vos connexions
  • Router automatiquement différents services via différents serveurs
  • Optimiser les performances avec des règles intelligentes
  • Bloquer les publicités et trackers indésirables

🚀 Installation Rapide

Étape 1 : Installer l'application

Téléchargez l'une des applications supportées depuis l'App Store (Loon, Shadowrocket, ou Stash).

Étape 2 : Ajouter vos serveurs proxy

Obtenez un abonnement proxy auprès d'un fournisseur de confiance et ajoutez l'URL de souscription dans l'application.

Étape 3 : Importer la configuration

Téléchargez le fichier de configuration correspondant à votre application et importez-le.

Pour Loon :

# Ouvrez Loon > Configuration > Importer depuis un fichier # Sélectionnez : loon/complete.conf

Pour Shadowrocket :

# Ouvrez Shadowrocket > Configuration > Ajouter une configuration # Sélectionnez : shadowrocket/complete.conf

Pour Stash :

# Ouvrez Stash > Profils > Nouvel profil # Sélectionnez : stash/complete.yaml

Étape 4 : Activer le proxy

Activez la connexion VPN dans l'application. iOS vous demandera l'autorisation - acceptez pour permettre au proxy de fonctionner.

Étape 5 : Vérifier le fonctionnement

Testez votre connexion en visitant un service comme YouTube ou Netflix. Le trafic devrait maintenant être routé via le proxy selon les règles configurées.

⚙️ Personnalisation Avancée

Les configurations peuvent être personnalisées selon vos besoins :

  • Ajoutez vos propres règles de domaines
  • Créez des groupes de proxys personnalisés
  • Configurez des scripts pour des fonctionnalités avancées
  • Optimisez les règles pour vos cas d'usage spécifiques

Consultez le README.md pour plus d'informations sur la structure des règles et comment contribuer au projet.
